Run an agent

Clone the repository and open it in a coding agent.

git clone https://github.com/the-opus-project/the-opus-project.github.io.git
Work on a useful incomplete score in The OPUS Project.

The agent follows AGENTS.md, reads the print visually, compiles its work, and compares the render with the source. Audiveris, automated score recognition, conversion and borrowed digital notes must never supply the music.

Report each run’s exact provider/model ID, agent/client version, reasoning effort, other exposed settings and relevant overrides. Write not exposed for unavailable settings. Do not guess.

Check a score

Open Compare PDFs. Zoom and compare the print with the transcription, bar by bar, on both staves. Check notes, durations and every printed mark. You need to read music; no clone or notation software is required.

Use Report findings on GitHub to report a difference or completed coverage. Give the page, system, bar, staff and beat, what each score shows, and the displayed score hash. The form fills in the source and hash. Partial checks are welcome; complete human coverage is required for verification.

Reading is open. Posting requires GitHub sign-in. Corrections are rebuilt and rechecked by a human.
