Preparing the first review?

Use the three-file inputs once: the original printed PDF, the rendered PDF and the supplied .ly file. Score Desk checks file identities and creates the package for you.

An agent can also prepare the ZIP using the package format instructions. Contributors do not need to edit JSON or calculate hashes.

One package through each review round

  1. Paint and comment. Select Draw, highlight a passage, and describe the error. Colors, undo/redo and finding focus help keep observations clear.
  2. Export AI task. Download the ZIP and copy its generated prompt. It includes the original, exact code and rendering, marked pages, context images and readable comments.
  3. Import AI response. Inspect the proposed changes and retain the new revision. The previous files and marks remain available.
  4. Review this returned revision. Compare the correction with the source. Mark it correct, request another correction, or ask for clarification.
  5. Finish and export. Choose whether you checked the corrections, the entire work, or only part. The package records that scope, exact revision, findings and history automatically.

Accepting a response or exporting a package does not verify a score. Complete review coverage and approval of the exact revision are still required.

Keep a portable copy

Download a review or completed-review ZIP before moving to a different browser or site. Browser storage can be cleared, and saved work on an old localhost port does not automatically appear here.

An AI response must match a task retained in the browser where you import it. Finish outstanding response rounds on their original site, or reopen a review package here and export a new task. Ordinary review packages do not restore every issued task.
