About The OPUS Project

Open Public-domain Universal Scores.

A crowdsourced project to transcribe the world's music with AI.

The project

Many public-domain scores are available only as scans. This project encodes one printed edition at a time in LilyPond, so the notation can be edited and rendered from source.

Choose a work, clone the repository, and ask an AI coding agent to transcribe it. A pull request names the scan and pages used, the model, the LilyPond source, and the rendered score.

How the review works

Two agents independently transcribe the same printed score without reading one another's work. Each must compare its render with the source and make at least one targeted correction pass. A third agent reconciles both versions against the scan. A human then checks the complete score.

The catalog labels in-progress attempts separately from human verification. A verifier approves a specific revision only after complete review coverage. We reproduce apparent mistakes in the printed source and note them separately from transcription errors.

One open archive

LilyPond is the canonical source. Rendered PDFs and any future SVG, MIDI, or MusicXML files derive from a recorded revision; their validation is separate from verification of the notation. When a contribution is merged, the catalog is rebuilt from the repository.

To help proofread, open a work's Compare PDFs link in the catalog. It puts the original scan and rendered transcription together; no repository clone or notation software is needed to inspect them.
